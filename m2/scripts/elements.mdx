## 概览

元素功能用于给装备附加额外的百分比属性。元素值只统计人物当前穿戴在身上的装备，背包里的装备不会参与计算。

元素值通常按百分比理解，例如 `10` 表示 `10%`，`100` 表示 `100%`。

## 元素编号

| 编号 | 名称 | 简单说明 |
| --- | --- | --- |
| `0` | 暴击几率增加 | 提高触发暴击的概率 |
| `1` | 攻击伤害增加 | 先提高基础伤害，再计算防御 |
| `2` | 物理伤害减少 | 降低受到的物理伤害 |
| `3` | 魔法伤害减少 | 降低受到的魔法伤害 |
| `4` | 忽视目标防御 | 攻击时减少目标防御参与计算 |
| `5` | 所有伤害反弹 | 受到伤害后反弹一部分真实伤害 |
| `6` | 增加目标暴率 | 击杀目标后提高目标身上装备掉落概率 |
| `7` | 人物体力增加 | 提高最大 HP |
| `8` | 人物魔力增加 | 提高最大 MP |
| `9` | 怒气恢复增加 | 提高怒气增长速度 |
| `10` | 合击攻击增加 | 提高合击技能伤害 |

## 脚本命令

### 检查装备元素

```txt
CHECKNEWITEMVALUE 位置 属性 比较符 值
```

参数含义：

| 参数 | 说明 |
| --- | --- |
| `位置` | 装备穿戴位置编号，只能检查身上装备 |
| `属性` | 元素编号，范围 `0..10` |
| `比较符` | 支持 `=`、`>`、`<`，其他写法按 `>=` 处理 |
| `值` | 要比较的数值 |

示例：

```txt
#IF
CHECKNEWITEMVALUE 0 1 > 20
#ACT
SENDMSG 7 当前位置装备的攻击伤害增加大于20%
```

上例表示：检查 `位置 0` 的装备，元素 `1`（攻击伤害增加）是否大于 `20`。

### 设置装备元素

```txt
SETNEWITEMVALUE 位置 属性 操作符 值
```

参数含义：

| 参数 | 说明 |
| --- | --- |
| `位置` | 装备穿戴位置编号，只能修改身上装备 |
| `属性` | 元素编号，范围 `0..10` |
| `操作符` | 支持 `+`、`-`、`=` |
| `值` | 要增加、减少或设置的数值 |

写入规则：

- `+`：在原元素值上增加。
- `-`：在原元素值上减少，最低不会低于 `0`。
- `=`：直接设置为指定值。
- 单件装备单项元素最终范围为 `0..100`。

示例：

```txt
#ACT
SETNEWITEMVALUE 0 1 + 5
SENDMSG 7 当前位置装备的攻击伤害增加提升了5%
```

上例表示：给 `位置 0` 的装备增加 `5%` 攻击伤害增加。

## 变量显示

可以用 `<$VALUE1>` 到 `<$VALUE11>` 显示人物当前穿戴装备的元素总值。

变量和元素编号的对应关系是：

| 变量 | 对应元素 |
| --- | --- |
| `<$VALUE1>` | 元素 `0`：暴击几率增加 |
| `<$VALUE2>` | 元素 `1`：攻击伤害增加 |
| `<$VALUE3>` | 元素 `2`：物理伤害减少 |
| `<$VALUE4>` | 元素 `3`：魔法伤害减少 |
| `<$VALUE5>` | 元素 `4`：忽视目标防御 |
| `<$VALUE6>` | 元素 `5`：所有伤害反弹 |
| `<$VALUE7>` | 元素 `6`：增加目标暴率 |
| `<$VALUE8>` | 元素 `7`：人物体力增加 |
| `<$VALUE9>` | 元素 `8`：人物魔力增加 |
| `<$VALUE10>` | 元素 `9`：怒气恢复增加 |
| `<$VALUE11>` | 元素 `10`：合击攻击增加 |

注意：元素编号从 `0` 开始，变量编号从 `1` 开始。所以攻击伤害增加是元素 `1`，显示变量是 `<$VALUE2>`。

示例：

```txt
#ACT
SENDMSG 7 你的攻击伤害增加总值为：<$VALUE2>%
SENDMSG 7 你的忽视目标防御总值为：<$VALUE5>%
```

## 战斗公式

### 暴击几率增加

暴击几率增加会提高触发暴击的概率。

简单理解：

- `100` 约等于额外增加 `100%` 暴击概率。
- 只影响“是否暴击”，不改变暴击后的倍数。
- 当前暴击伤害仍按二倍伤害处理。

### 攻击伤害增加

攻击伤害增加会先提高基础伤害，然后再计算目标防御。

简单理解：

```txt
基础伤害 -> 攻击伤害增加 -> 计算防御 -> 计算减伤 -> 最终伤害
```

例如基础伤害是 `100`，攻击伤害增加是 `50%`，那么会先变成 `150`，再去计算目标防御。

### 物理伤害减少

物理伤害减少用于降低受到的物理伤害。

简单理解：

- 先计算防御，防御后还有伤害时才会继续减少。
- `50` 表示物理伤害减少 `50%`。
- 参与公式时最多按 `100%` 处理。
- 如果原本已经有伤害，减伤后最低保底 `1` 点伤害。

### 魔法伤害减少

魔法伤害减少用于降低受到的魔法伤害。

简单理解：

- 先计算魔法防御，防御后还有伤害时才会继续减少。
- `50` 表示魔法伤害减少 `50%`。
- 参与公式时最多按 `100%` 处理。
- 如果原本已经有伤害，减伤后最低保底 `1` 点伤害。

### 忽视目标防御

忽视目标防御会减少目标防御参与计算的比例。

简单理解：

- `50` 表示目标防御只按一半计算。
- `100` 表示不计算目标防御。
- 参与公式时最多按 `100%` 处理。
- 只影响目标防御，不影响物理伤害减少、魔法伤害减少、护盾等其他减伤效果。

### 所有伤害反弹

所有伤害反弹会在自己受到伤害后，把一部分伤害反弹给攻击者。

简单理解：

- 受到 `100` 点伤害，反弹 `20%`，攻击者会额外受到 `20` 点反弹伤害。
- 反弹伤害是真实伤害，不再计算防御。
- 反弹不会继续触发第二次反弹。

### 增加目标暴率

这里的“暴率”指击杀目标后，目标身上装备掉落的概率，不是暴击。

简单理解：

- 击杀目标后，会提高目标身上装备掉落概率。
- `100` 表示额外增加 `100%` 掉落概率。
- 地图禁止掉落、装备禁止掉落等规则仍然优先。
- 当前只影响目标身上装备，不影响背包物品散落。

### 人物体力增加

人物体力增加会提高最大 HP。

简单理解：

- `20` 表示最大 HP 增加 `20%`。
- 只提高上限，不会自动把当前 HP 补满。
- 装备变化或脚本修改元素后，上限会重新计算。

### 人物魔力增加

人物魔力增加会提高最大 MP。

简单理解：

- `20` 表示最大 MP 增加 `20%`。
- 只提高上限，不会自动把当前 MP 补满。
- 装备变化或脚本修改元素后，上限会重新计算。

### 怒气恢复增加

怒气恢复增加会提高怒气增长速度。

简单理解：

- `50` 表示每次怒气增长提高 `50%`。
- 只影响怒气增长，不影响怒气消耗。
- 怒气仍然受最大值限制。

### 合击攻击增加

合击攻击增加只影响合击技能伤害。

简单理解：

- `50` 表示合击技能伤害提高 `50%`。
- 只对合击技能生效。
- 普通攻击和普通技能不受这个元素影响。
